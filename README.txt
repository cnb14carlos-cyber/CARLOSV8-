===================================================
            CARLOSV8 - REPRODUCTOR WEB
===================================================

¡Bienvenido a tu proyecto de música web CarlosV8!

CONTENIDO DEL ARCHIVO ZIP:
- index.html   : La página web principal estilo Spotify.
- logo.jpg     : Tu imagen / avatar oficial con diseño CarlosV8.
- README.txt   : Este archivo con las instrucciones.

CÓMO USARLO EN TU ORDENADOR:
1. Descomprime esta carpeta .zip en tu ordenador.
2. Haz doble clic en el archivo `index.html`.
3. Se abrirá automáticamente en tu navegador web (Chrome, Edge, Firefox, Safari).
4. Introduce cualquier nombre en el inicio de sesión y ¡disfruta de tu música sin anuncios!
